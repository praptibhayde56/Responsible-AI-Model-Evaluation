# Responsible AI & Model Evaluation

## Experiment 10 – Deep Learning Lab

### Aim
To evaluate a classification model beyond accuracy, examine potential bias, and explain predictions using SHAP.

### Dataset
Titanic dataset.

### Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- SHAP

### Implementation
1. Loaded and preprocessed the Titanic dataset.
2. Trained a Random Forest classifier.
3. Evaluated the model using a confusion matrix, accuracy, precision, recall, and F1-score.
4. Compared prediction accuracy across male and female passengers.
5. Generated SHAP summary and waterfall plots.

### Conclusion
The experiment demonstrates the importance of evaluating model performance beyond accuracy, investigating potential subgroup bias, and using explainability techniques to understand model predictions.
